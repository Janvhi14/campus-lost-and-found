# Campus Lost and Found Portal with Image Matching

A Flask web application where students and staff report lost and found items.
Photos and descriptions are compared using OpenCV and TF-IDF to suggest matches.

## Tech stack
Python, Flask, SQLite, OpenCV, scikit-learn, Bootstrap

## Setup
1. `python -m venv venv`
2. `venv\Scripts\activate`
3. `pip install -r requirements.txt`
4. `python run.py`
5. Open http://127.0.0.1:5000
